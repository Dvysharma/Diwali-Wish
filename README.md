# Diwali Wish

A festive Diwali greeting page with a short film, diya interaction, animated particles, and custom background music.

## Features
- Interactive Diwali greeting experience
- Short film modal with play/pause controls
- Diya light-up animation with celebratory effects
- Separate music for the film and diya moment
- Mobile-friendly responsive layout

## Run locally
Open the project in a browser, or serve it locally from the project folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```
